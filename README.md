# personal-site

Минималистичный личный сайт-визитка и блог на HTML, CSS и JavaScript.
Установка зависимостей и сборка не нужны.

## Файлы

- `index.html` — тексты, ссылки и записи блога.
- `styles.css` — оформление, адаптация под телефон и клавиатурная навигация.
- `script.js` — автоматическое обновление года в подвале.
- `favicon.svg` — иконка сайта.

## Публикация

GitHub Pages уже настроен. Последняя проверенная публикация исходной версии
(`e0f6db8`) завершилась успешно.

Ожидаемый стандартный адрес: https://codeclaudeai.github.io/personal-site/
Точный действующий адрес и источник публикации доступны в **Settings → Pages**.
Статус обновлений — во вкладке **Actions**, процесс **pages build and deployment**.

Изменения в отдельной ветке не обновляют опубликованную страницу.
После принятия pull request в `main` дождитесь успешной публикации в Actions.

## Редактирование с iPhone

1. Откройте репозиторий в Safari и войдите в GitHub.
2. Откройте `index.html` и выберите редактирование файла (значок карандаша).
3. Измените нужный текст или ссылку.
4. Сохраните через **Commit changes**. Для проверки перед публикацией выберите
   создание новой ветки и pull request.
5. После принятия изменений в `main` проверьте Actions и откройте сайт заново.

Текущие ссылки: Telegram `@httpsbotnet` и GitHub `@codeclaudeai`.
Карточки TikTok и «Ещё» скрыты до появления реальных адресов.
Для новой соцсети скопируйте существующий элемент `<a class="social-card">…</a>`
внутри `social-grid` и замените адрес, название и подпись.

## Блог

Блог остаётся статическим: редактора записей на сайте нет.
Чтобы добавить первую запись, замените `<article class="post empty-post">…</article>`
внутри `posts`, например:

```html
<article class="post">
  <div class="post-meta"><time datetime="2026-09-09">9 сентября 2026</time></div>
  <h3>Заголовок записи</h3>
  <p>Текст записи.</p>
</article>
```

Следующие записи добавляйте выше предыдущих.
Это пример для редактирования, а не опубликованная запись.

## Проверка перед сохранением

- Ссылки ведут на нужные профили, внутренних ссылок на `#` без цели нет.
- Локальные пути к стилям, скрипту и иконке остаются относительными:
  сайт работает в подпапке `/personal-site/`.
- При изменении названия или описания обновите также Open Graph и Twitter
  метаданные в начале `index.html`.
- В разделе блога публикуйте только готовые тексты.

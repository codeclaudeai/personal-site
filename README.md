# personal-site

Минималистичный личный сайт-визитка и блог.

## Файлы
- `index.html` — содержимое сайта
- `styles.css` — оформление и мобильная адаптация
- `script.js` — небольшая клиентская логика

## Публикация через GitHub Pages
В настройках репозитория открой **Settings → Pages**, выбери **Deploy from a branch**, затем ветку **main** и папку **/(root)**.

Перед публикацией замени заглушки Telegram/TikTok в `index.html` на свои ссылки.
